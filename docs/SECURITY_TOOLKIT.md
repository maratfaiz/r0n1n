# Security / white-hat инструментарий

## Рамки применения

Все инструменты в этом разделе предназначены **только** для: собственных
устройств пользователя, лабораторных/учебных стендов, CTF-соревнований и
авторизованного пентеста с явным разрешением владельца системы. Это прямое
продолжение границ проекта из `VISION.md`.

Проектные требования к реализации (обязательны для каждого инструмента из
этого документа, проверяются на код-ревью после старта разработки):

- «Острые» операции (запись/эмуляция на реальное железо, брутфорс,
  BadUSB-выполнение) требуют подтверждения в UI.
- Региональный TX-lock для Sub-GHz — настраиваемая опция, не жёстко
  зашитое ограничение и не полное её отсутствие (баланс между легальностью
  по умолчанию и свободой владельца устройства).
- Rolling-code функции — только демонстрация риска с явным
  предупреждением о десинхронизации замка; не позиционируются как «взлом
  соседского шлагбаума».
- Каждый инструмент — с однострочной пометкой «что это и когда легально» на
  карточке приложения (см. `UX_DESIGN.md`, контекстные действия/карточки).

## Организация по доменам

Двойной вход для каждого домена — мастер (пошагово, для новичка) и
advanced-режим (все параметры, для эксперта) — прямое применение принципа
«прогрессивное раскрытие сложности» из `VISION.md`.

### RF security (Sub-GHz)

Анализатор спектра/частот в пределах CC1101 (не SDR — см. `HARDWARE.md`),
capture/replay, fixed-code брутфорс (лабораторно), декодеры известных
протоколов (POCSAG, TPMS, погодные станции — используя уже существующие в
Unleashed декодеры).

### NFC/RFID

Словарные/mfkey32/nested/card-only атаки на MIFARE Classic, MIFARE Plus SL3,
magic-теги, RFID Fuzzer, определение типа карты/ридера.

### Hardware/embedded

SWD/JTAG через DAP Link — дамп/отладка прошивок, UART/SPI/I2C-мост, дамп
SPI-flash, i2c-сканер, базовый логический анализатор, фаззинг сигналов на
GPIO.

### USB security

BadUSB/BadKB (USB+BLE), редактор DuckyScript/JS с шаблонами и построчным
объяснением каждого шага, демонстрация exfiltration в виртуальный
disk-образ (без реальной отправки данных наружу без явного согласия).

### IoT / 2.4 ГГц (модульно, честно помечено в UI)

nRF24 mousejack/сниффинг, ESP32-инструменты (Wi-Fi scan/deauth/Evil
Portal/PCAP), BLE-разведка — всё за значком «требуется внешнее железо»
(см. `HARDWARE.md`).

### Auth/defensive — раздел «защити себя»

U2F, в перспективе FIDO2/passkey, TOTP/HOTP, FindMy-подобный поиск
устройства — инструменты для обычных пользователей, не только пентестеров;
важная часть смешанной аудитории проекта.

### CTF/debugging

Заметки, таймер, hex-view, конвертеры, экспорт находок в companion
(см. `UNIQUE_FEATURES.md`, учебный/CTF-слой).

## Связь с профилями

Полный список security-инструментов виден в профиле **Pentest**; в
**Everyday** видны только «безопасные» (auth/defensive) инструменты; в
**CTF** — тот же набор что в Pentest плюс CTF/debugging-слой. Подробности
механики профилей — `UX_DESIGN.md`.
